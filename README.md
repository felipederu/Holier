# Holier 🕊️

**A personal web app for spiritual tracking, battling lust, and fostering habits of purity.**  
Built with React, TypeScript, and Supabase.

---

## ✨ Project Overview

**Holier** is a web application designed to help Christians grow spiritually by tracking daily habits, struggles, and reflections. Its purpose is to provide a private, simple tool for:

- Logging daily spiritual state (victory, struggle, relapse)
- Writing reflections and personal prayers
- Accessing relevant Bible verses
- Visualizing progress over time
- (Optional) Receiving AI-based companionship rooted in Scripture

Holier combines solid web development practices with a meaningful, real-life purpose.

---

## 🛠️ Tech Stack

| Tool             | Purpose                        |
|------------------|--------------------------------|
| **React**        | Frontend SPA                    |
| **TypeScript**   | Static typing                   |
| **Zustand**      | Global state management         |
| **React Router** | Routing                          |
| **Supabase**     | Backend: Database, Auth, API     |
| **TailwindCSS**  | Fast, consistent styling         |
| **Vitest**       | Unit testing                     |
| **Playwright**   | End-to-end testing               |
| **GitHub Actions** | CI/CD                          |
| **Vercel**       | Deployment                       |
| **OpenAI API**   | (Optional) AI-powered companion   |

---

## 🚩 MVP Features

✅ Secure signup / login via email (Supabase)  
✅ Dashboard with current state and progress summary  
✅ Daily spiritual tracking  
✅ Visual progress stats (last 30 days, overall trends)  
✅ Auto-suggested Bible verses based on user state  
⬜ Optional AI-powered companion (in progress)
